# 실제 원고를 확인하는 검토 SOP — AS-SOP-001

목적: 근거 없는 품질 통과 보고를 막고 실제 원고를 단계별로 검토한다. 반복되는 품질 중심 작업에서 사용하며 작은 일회성 편집에 일률적으로 추가하지 않는다.

입력: 실제 이전 원고, 현재 원고, 원문 보존 조건, 기존 형식 검사기, 원래 완료 기준. 실제 파일과 명령 실행 증거는 소비 프로젝트가 확인한다. 범용 평가기는 제출된 사본만 검사한다.

1. **Capture.** 실제 이전 원고를 보존하고 현재 입력과 SOP의 SHA-256을 고정해야 한다. 어색한 이전 문장을 지어내면 안 된다. 원본이 없으면 없다고 기록한다.
2. **Review.** 문단과 문장을 문맥 속에서 직접 읽어야 한다. 유지/수정, 구체적인 판단 이유, 각 문장에 실제로 있는 검토 구절을 기록한다. 의미·청중·자연스러운 표현·원문 충실도를 확인한다. 반복 총평을 자동으로 채우거나 형식 검사를 편집자의 판단으로 취급하면 안 된다.
3. **Check.** 검토한 현재 입력에 기존 검사기를 실제로 실행해야 한다. 명령·도구·규칙·종료 코드·출력 로그 지문을 연결한다. 실패하면 멈춘다. 조용한 대체 실행과 허위 실행 기록은 금지한다.
4. **Verify.** 문장 누락, 순서, 원고·근거 변경, 범위 보존을 확인해야 한다. 입력이 바뀌면 검토로 돌아간다. `evals/sop-review.mjs --report <파일>` 또는 기존 `--cost-selection`의 `reviewWorkflow`로 검사한다. `qualitySensitive: true`인 완료 계획은 이 기록이 필수다.
5. **Deliver.** 프로젝트의 기존 승인·제작 절차로 이어간다. 기계 검사로 문체 품질, 독립 검토, Agent의 실제 읽기, 모든 호스트의 준수를 인증하지 않는다. 생략한 검사와 남은 검토를 구분해 보고한다.

`--through review`는 중간 기록만 허용하며 최종 제작 승인이 아니다. 호스트는 최종 검사를 실제 소비 경로에 연결해야 한다. 변경 전 정상·이전 실패·우회 사례를 고정한다. `node evals/verify-sop-review.mjs`는 22개 계약 사례와 실제 AS-US-001 경로 연결을 검사한다.

참조 소비 경로: LingoMotion은 실제 원고·검사 로그를 연결하고 검토가 남으면 음성 제공자를 호출하기 전에 멈춘다. 해당 경로의 동작 근거이며 모든 시스템의 적용이나 청취 품질을 보장하지 않는다.
